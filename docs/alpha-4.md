# Alpha 4: Helix Abyss

Alpha 4 adds the Helix Abyss Plasma colour scheme, dark Breeze-based Qt and GTK
integration, a dark Breeze SDDM login, and a repository-owned wallpaper. Ghostty
moves to Catppuccin Mocha, VS Code uses its built-in Abyss theme, supported
browsers receive dark policy and official Dark Reader, and Hyprland, Waybar,
Mako, and Fuzzel share the same palette. Obsidian remains an explicitly
documented per-vault dark-theme choice.

A future release may be marked after runtime validation with:

```bash
git tag -a v0.4.0-alpha.4 -m "Helix NixOS Alpha 4"
```
